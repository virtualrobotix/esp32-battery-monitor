## 🆘 TROUBLESHOOTING

### Problema: "Non si apre in Safari"
```
Soluzione:
- Click destro sul file .html
- "Apri con" → Safari
- O trascina file su icona Safari
```

### Problema: "PDF troppo grande"
```
Soluzione:
- Usa PDF separati invece di COMPLETO
- Oppure imposta Scala: 85-90%
```

### Problema: "Tabelle tagliate"
```
Soluzione:
- Impostazioni stampa → Scala: 85%
- Oppure Layout: Orizzontale
```

### Problema: "Link non funzionano"
```
Soluzione:
- Usa Safari (migliore supporto)
- Verifica "Salva come PDF" (non "Esporta")
```
